# HomePi Hub (working title)

A Pi-native real estate marketplace: free property search and deal-analysis
tools for investors, paid advertising and lead-generation products for real
estate professionals, with payments denominated in Pi and the app running in
the Pi Browser.

The business model mirrors the ad-driven / lead-gen structure of major
property portals: the consumer side is always free, and revenue comes from
professionals paying for exposure (sponsored regional visibility, featured
listings, banner placements).

## Repository contents

This repository currently holds the go-to-market and partner-facing
documentation. Application code (frontend, backend services, Pi SDK
integration) will be added in later phases.

| Path | Contents |
